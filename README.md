# sindy.ai

Sindy Huang’s product and UX design portfolio. A responsive, buildless static site.

## Preview

Run `python3 -m http.server 8765 --directory dist` and open http://localhost:8765.

## Files

- `dist/index.html`: homepage
- `dist/style.css`: shared styles
- `dist/*.html`: project stories
- `dist/assets/`: selected project images and local font

## Deployment

Publish `dist/` using any static host. No install or build is needed. The private Sites deployment is configured in `.openai/hosting.json`. GitHub stores the source; GitHub Pages can optionally serve `dist/` via a Pages workflow.
